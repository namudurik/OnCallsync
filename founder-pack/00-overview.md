# OnCallsync Founder Pack

This founder pack is a practical operating system for validating and launching
OnCallsync: an on-call scheduler that lives inside Google Calendar for tech
teams.

Use this in order:

1. `01-icp-and-positioning.md`
2. `02-customer-interview-script.md`
3. `03-pilot-offer-and-outreach.md`
4. `04-pricing-test-sheet.csv`
5. `05-mvp-scope-and-build-plan.md`

## Success criteria for this phase

You should not start broad product development until you hit:

- 10 completed ICP interviews
- 3 teams with clear paid pilot intent (or signed pilot)
- A repeated "top pain" pattern you can solve with a tiny MVP

## Suggested operating cadence

- Monday: outbound + interview scheduling
- Tuesday-Thursday: interviews and notes
- Friday: pricing tests, pilot asks, and decision review

## Non-goals right now

- Building every scheduling edge case
- Supporting multiple calendars/providers
- Optimizing UI polish before validation

Focus on proving pain, urgency, and willingness to pay first.
